## 影响图

R1 → 发布与接入 → 凭据签发/认证 → 场景权限 → REST/MCP/回执/审批/附件 → 回归与迁移。

R2–R6 → 业务蒸馏工作台 → 版本化项目与分析提案 → 证据引用/受管资料 → 不可变交接资料 → 智能业务顾问既有建模来源 → 候选治理。

R7–R8 → 对话优先的协作工作台 → 持久对话轮次与显式工具调用 → 有界证据/结构/网页读取和业务审查技能 → 人工澄清 → 待采用阶段建议 → 既有不可变交接。画布用于查看和确认阶段结论，不再以表单精修作为默认业务整理流程。

必要消费者补充：场景永久删除计划需识别新增凭据/蒸馏引用，避免外键错误成为用户可见 500。不可变蒸馏历史阻止直接永久删除，正常退役仍沿用原机制。共享基线不自动混入每个场景；用户可复制到目标场景并发布该场景的资料版本。

资料类型消费者复核：`distillation` 交接只进入建模资料与顾问来源链路，连接器目录、连接器目标解析、旧顾问数据库候选和映射草稿自动修复使用支持类型白名单。交接资料不再被误报为 SQL 连接器、挤占有界数据库候选，或参与运行连接绑定；直接绑定请求返回稳定冲突。

用户追加参考工作台后，只读检查其表格/字段、图谱和产出界面。吸收资料角色（输入、知识、历史结果、过程记录）和结果逆向协作入口；不复制参考系统数据、布局或行业逻辑。用户进一步明确以 AI 对话、人机问答和引导为主，因此重做默认工作台，结构化编辑器仅保留在精修面板。关联歧义、复合条件和缺失证据必须保留为核对问题，不将置信度当作事实证明。

不改变 Provider、正式调用数据绑定、工作流执行器、部署方式或行业实现。目标页面调查复用既有 DNS 固定、私网策略和无自动跳转的受控 HTTP 传输；执行匿名 HTTPS GET，返回有界正文、哈希、时间和限制。网站自动登录和动态流程遍历目前没有受治理适配器，遇到登录页明确报告调查未完成，允许补充人工观察/导出。未来登录适配器需独立定义授权范围、加密凭据保管、人工挑战和证据快照契约。

对话入口必要安全消费者：共享凭据字符串检测补齐带引号的 JSON key，拒绝密码、令牌等文本进入消息和模型；目标 JSON 经过结构化脱敏后保留安全业务字段，防止重复扫描误删整个响应。已有对话的项目禁止改绑场景，避免历史对话随新场景权限扩大可见范围。
