- 没有使用真实客户账户验收业务系统登录；没有调用真实 LLM 评价推理质量。脚本模型证明工具编排与持久闭环，不能证明核心业务识别正确。最终业务验收应选一个专家熟悉的核心结果，提供对应历史输入/结果及例外记录，逐项核对 Agent 的引用、关联、缺口和图谱结论。
