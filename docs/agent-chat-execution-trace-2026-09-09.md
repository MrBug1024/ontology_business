影响图：聊天/SSE与已有 event-log 入口 -> TurnProgress -> 已有 AgentTurnRun/AgentTurnEvent -> 现有 worker 与统一能力调用 -> 定向测试、前端测试/构建、真实浏览器、隔离 PostgreSQL。

不改变数据库结构、发布、租户权限、确认/幂等规则或第三方能力输出契约。事件沿用既有 `invoking_tools` 类型，新增可选、有界 `tool_step`；旧消费者仍能读取阶段状态。公开模型正文中工具调用前的说明可作为“分析说明”回看，模型私有 reasoning 不采集。

浏览器验收扩展：流式更新、最终历史刷新不应强制把正在阅读过程的用户拉到消息底部，因此影响范围包含 `useAgentDurableTurns` 的进度滚动回调和 AgentChat 历史刷新时的跟随条件；发送新消息、主动打开会话仍滚动到最新消息。

回答约束扩展：现有历史把通用执行错误断言为已查明根因，并多次替换业务筛选条件重试。`agent_prompt_policy` 的验证 Agent 说明要求简洁区分失败、无业务结果和未知根因，不凭一般错误反复改条件。此为模型行为约束，不修改能力执行/重试内核，不重写旧会话正文。
