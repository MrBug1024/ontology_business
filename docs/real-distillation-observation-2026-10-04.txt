一个处理团队可负责多种服务类型，但每种服务类型只由一个团队负责 → handling_team:service_type = 1:N

规则2：优先级验证（Priority Validation）

触发条件： 完整性检查通过后

规则：

IF priority NOT IN ["low", "normal", "high"]:
    BLOCK with INVALID_PRIORITY

输出： 若非法：

{
  "request_id": "<request_id>",
  "route": "rejected",
  "reason": "Invalid priority value: '<priority>'. Allowed: low, normal, high"
}
规则3：紧急分流（Routing）

触发条件： 完整性和优先级验证均通过

规则：

IF priority == "high":
    route = "expedited"
ELSE:
    route = "standard"  // low, normal

输出：

{
  "request_id": "<request_id>",
  "route": "expedited|standard",
  "reason": "Routed to <route> based on priority=<priority>"
}
