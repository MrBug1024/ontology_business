# 代理记账业务逻辑

## 一、账务处理逻辑

### 1. 收入确认规则
- 商贸业（商品销售）：客户取得商品控制权（发货、签收完成）时确认收入；预收货款不计入收入，挂合同负债。
- 制造业：现货销售：货物出库、客户验收后确认；设备（履约周期超1年）：按照完工百分比（时段法）分期确认收入。
- 服务业（咨询、运维、租赁）：属于时段履约义务，在服务提供的周期内，按月/按完工进度分期确认收入。
- 开票与会计收入的差异处理：增值税开票时点≠会计收入确认时点。先开票、货/服务未提供：增值税申报缴税，会计账务计入「合同负债」，不确认营业收入；货已交付、暂时未开票：会计正常确认收入，增值税做未开票收入申报。
- 跨期收入处理：严格遵循权责发生制，当年预收次年服务费、货款，全部计入合同负债，在后续履约的所属会计期间分批结转收入。

### 2. 成本结转方法
- 品种法：大批量、单步骤生产（食品、建材、采掘），按产品品类归集料、工、费，月末用约当产量划分在产品和完工产成品成本。
- 分步法：多工序流水线连续生产（纺织、汽车、钢材），分生产车间逐步归集成本。
- 分批法（订单法）：单件、小批量定制生产（设备定做、船舶、模具），按生产批号归集成本。
- 服务业成本归集：直接把对应项目的人工、外包服务费、场地费、耗材，归集计入「合同履约成本」，在确认收入的同期同步结转为主营业务成本。

### 3. 费用报销审核
- 必须取得发票才可税前扣除的业务：外购货物、服务费、房租、运输费、住宿费、广告费等对外采购的支出。
- 无需发票的业务支出：员工工资薪金、现金差旅补贴、福利费发放、违约金（非价外费用）、500元以内零星个人收款。
- 业务招待费扣除限额：实际发生额的60%，且不能超过当年营业收入的5‰，二者取最小值。
- 差旅费：交通费、住宿费凭发票全额扣除；公司制度标准内的差旅补贴不需要发票。
- 会议费：可全额税前扣除，不属于招待费。完整附件：会议通知、参会签到表、会议现场资料、场地租赁发票。

### 4. 固定资产处理
- 确认标准：持有目的为生产经营使用、使用寿命超过1个会计年度的有形资产。实务代账通用口径：单价≥5000元作为固定资产。
- 折旧方法：年限平均法（直线法，代理记账最常用）、工作量法、双倍余额递减法。
- 税法最低折旧年限：房屋建筑物20年；机器设备10年；运输车辆4年；电子设备3年。

### 5. 往来款项处理
- 应收、应付严格按照合同、对账确认单入账；回款/付款时逐笔核销。
- 坏账准备计提（账龄分析法）：1年内不提或少提；1~2年计提10%；2~3年计提30%；3年以上全额计提。
- 应付账款长期无需支付：转入「营业外收入」，正常缴纳企业所得税。
- 股东长期挂账的其他应收款：年度终了未归还，视同股东分红，代扣个税。

## 二、税务申报逻辑

### 1. 增值税申报
- 一般纳税人：按月申报，采用一般计税，进项票可以抵扣销项。
- 小规模纳税人：按季申报，简易计税，进项不能抵扣，现行有阶段性减免优惠。
- 进项抵扣审核：专票、海关缴款书等合规凭证才可抵扣；用于福利、免税项目的进项必须做进项转出。
- 视同销售：自产货物赠送、对外投资、无偿移送等，要核算销项税额进行纳税。
- 留抵退税：一般纳税人为小微企业、制造业等行业，信用等级达标、无税务违规，期末有进项留抵可申请退还。

### 2. 企业所得税预缴
- 季度预缴算法：常规按账面实际利润预缴；核定征收用「应税收入×应税所得率」。
- 亏损弥补：查账征收企业季度盈利可直接弥补近5年的以前年度亏损；核定征收不能弥补亏损。

### 3. 企业所得税汇算清缴
- 常见调增项目：业务招待费超支、广告费超标、无合规发票的支出、罚款滞纳金、职工福利费超限额、视同销售差异。
- 常见调减项目：国债利息、居民企业分红等免税收入；研发费用100%/75%加计扣除；500万以内固定资产一次性税前扣除。

### 4. 个人所得税申报
- 累计预扣法：逐月累计全年收入，减去6万起征点、社保公积金、专项附加扣除，套用年度税率表计算当期应扣个税。
- 年终奖二选一：①单独计税，奖金除以12找税率；②并入当年工资薪金，按综合所得计税。

### 5. 其他税种
- 印花税税率：借款合同0.005%；买卖合同、承揽合同、建设工程合同、运输合同、技术合同0.03%；租赁合同、保管合同、仓储合同、财产保险合同0.1%；土地使用权/房屋/股权转让书据0.05%；证券交易0.05%（2023年8月28日起减半）。
- 城建税：以当期实际缴纳的增值税、消费税为基数，7%/5%/1%三档（按地区）。
- 教育费附加3%、地方教育附加2%。
- 残保金：按单位在职职工人数、安置残疾人比例计算，小微企业有减免政策。
- 工会经费：按季度申报，社保金额为季度工资薪金合计数额的2%。

## 三、客户管理逻辑

### 1. 新接客户流程
- 收集资料：营业执照、法人及办税人身份信息、银行账户信息、往期凭证账簿、科目余额表、电子税务账号密码、代理记账委托合同。
- 期初数据录入：按交接时的期末科目余额表录入；无账套的盘点资产负债，建期初数。
- 建账规范：按企业类型选择会计准则（小企业准则/企业准则），区分一般纳税人和小规模。

### 2. 日常沟通规范
- 月度确认：每月核对收入、成本票据、银行流水、开票数据，确认税款金额、申报数据。
- 季度同步：利润情况、税负情况。
- 政策变更：以文字形式推送客户，标注对该企业的具体影响和调整操作。
- 风险提醒：发票异常、往来长期挂账、税负异常、费用缺票、股东借款等问题，提前告知风险点及整改方案。

### 3. 客户档案管理
- 档案内容：客户资质证照、委托合同、每期凭证报表、纳税申报表、交接单据、沟通记录、各类审批资料。
- 保管期限：会计凭证、账簿、申报表保管30年；委托合同等其他资料永久留存。

### 4. 到期续约流程
- 到期前30天首次提醒，到期前15天再次跟进确认。
- 总结当期服务内容、财税风险管控成果，说明后续服务保障，协商续约事宜。
- 调价考量：市场财税政策变化、企业业务量增长、账务复杂度提升、额外增值服务增加、人力成本变动。
