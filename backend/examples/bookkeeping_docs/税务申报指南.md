# 税务申报指南

## 增值税
- 一般纳税人：按月申报，一般计税方法，销项税额-进项税额=应纳税额
- 小规模纳税人：按季申报，简易计税，销售额×征收率（1%或3%）
- 申报期限：每月/季终了后15日内
- 进项抵扣：专票、海关缴款书、农产品收购发票等合规凭证
- 进项转出：用于集体福利、个人消费、免税项目的进项税额

## 企业所得税
- 季度预缴：按账面实际利润或应税收入×应税所得率
- 年度汇算清缴：次年5月31日前
- 税率：25%（一般）、20%（小型微利企业优惠）、15%（高新技术企业）
- 纳税调整：业务招待费（60%且5‰取小）、广告费（15%限额）、研发费用加计扣除（100%）

## 个人所得税
- 工资薪金：累计预扣法，年度税率3%-45%
- 专项附加扣除：子女教育、房贷利息、房租、赡养老人、继续教育、大病医疗
- 年终奖：单独计税或并入综合所得，择优选择

## 印花税
- 借款合同：0.005%
- 买卖合同/承揽/建设/运输/技术合同：0.03%
- 租赁/保管/仓储/财产保险合同：0.1%
- 产权转移书据：0.05%
- 证券交易：0.05%（2023.8.28起减半）

## 附加税费
- 城建税：7%（市区）/5%（县城）/1%（其他）
- 教育费附加：3%
- 地方教育附加：2%
- 计税依据：实际缴纳的增值税+消费税
