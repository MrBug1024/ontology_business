# 费用税前扣除标准

## 业务招待费
- 扣除限额：实际发生额×60% 与 营业收入×5‰ 取小
- 必备附件：正规餐饮/招待发票、招待事由、参与人员名单、业务对接记录

## 广告费和业务宣传费
- 扣除限额：营业收入×15%（化妆品/医药/饮料制造25%）
- 超支部分可结转以后年度扣除

## 职工福利费
- 扣除限额：工资薪金总额×14%

## 工会经费
- 扣除限额：工资薪金总额×2%
- 需取得工会经费收入专用收据

## 职工教育经费
- 扣除限额：工资薪金总额×8%
- 超支部分可结转以后年度扣除

## 利息支出
- 向金融企业借款：全额扣除
- 向非金融企业借款：不超过金融企业同期同类贷款利率计算的数额

## 捐赠支出
- 公益性捐赠：年度利润总额×12%以内扣除
- 超支部分可结转以后3年扣除

## 资产损失
- 需按规定向税务机关申报
- 坏账损失：需有相关证据（注销证明、破产判决、催收记录等）
