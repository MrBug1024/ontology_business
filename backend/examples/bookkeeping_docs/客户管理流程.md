# 客户管理流程

## 新接客户
1. 签订代理记账委托合同
2. 收集资料：营业执照、法人/办税人身份证、银行账户、往期凭证、科目余额表
3. 期初数据录入：按期末科目余额表录入资产、负债、权益
4. 建账：按企业类型选择会计准则，设置科目
5. 交接签字：形成交接单据，双方签字确认

## 月度服务
1. 收集原始凭证（发票、银行流水、工资表等）
2. 票据归类+索引
3. 编制会计分录
4. 勾稽校验（借贷平衡）
5. 生成纳税申报表
6. 金额判断：<1000元AI直接申报，≥1000元客户确认后申报
7. 申报回执反馈
8. 生成月度财务报表
9. 客户月度沟通确认

## 季度服务
1. 季度增值税申报（小规模纳税人）
2. 季度企业所得税预缴
3. 季度利润/税负情况同步

## 年度服务
1. 年度企业所得税汇算清缴（次年5月31日前）
2. 年度财务报表审计（如需）
3. 年度档案整理归档

## 风险提醒
- 发票异常：缺票、假票、票面信息不符
- 往来长期挂账：应收账款超1年、应付账款超2年
- 税负异常：税负率明显低于行业平均水平
- 股东借款：年度终了未归还，视同分红代扣个税
- 费用缺票：大额支出无合规发票

## 到期续约
- 到期前30天：首次提醒，总结服务内容
- 到期前15天：再次跟进，协商续约
- 调价因素：政策变化、业务量增长、复杂度提升、增值服务、人力成本
